How it works

Three roles, one clean loop.

01
💬

User sends a message

Any Telegram user messages the bot privately. All media types are supported — text, photos, videos, files, voice, audio, stickers, GIFs, video circles, location, and contacts.

02
📂

Bot creates a Forum Topic

On first contact, the bot creates a dedicated Forum Topic in your private admin group named after the user. Every subsequent message threads into that topic automatically.

03
↩️

Admin replies, user receives

Any admin replies inside the forum topic are forwarded back to the user's private DM in real time. Use /close to resolve and archive the ticket.

Features

Everything your support team needs.

📁

Full media support

Text, photos, videos, documents, voice messages, audio, stickers, GIFs, video circles, location pins, and contacts — all relayed bidirectionally.

🎫

Ticket lifecycle

Sessions open on /start, can be closed with /close, and reopen automatically when a user contacts the bot again after resolution.

🚫

Ban & unban users

Block spamming or abusive users directly from within their support topic using /ban. Lift restrictions instantly with /unban.

📢

Broadcast announcements

Send a message to all active, non-banned users at once using /broadcast — perfect for outage notifications or product updates.

📊

Stats dashboard

Check total sessions, active tickets, banned users, and today's message activity at any time with /stats via private DM.

⚡

Rate limiting

Per-user message throttling prevents flooding. Configure the message limit and time window via environment variables.

👍

Delivery receipts

The bot reacts to each user message with a thumbs-up emoji the moment it's forwarded — a subtle, non-intrusive confirmation.

🗃️

SQLite persistence

All sessions, ban states, and timestamps are stored in a lightweight SQLite database. No external DB required.

🚀

Webhook-based, Gunicorn-ready

No polling. PTB runs on a dedicated asyncio thread inside Gunicorn, with a /health endpoint for uptime monitors.

Commands

Every command, where it works.

👤  User — private DM with bot

/start Start a new support session, or resume an existing one
/help Show available commands and usage instructions

🛡️  Admin — inside a group forum topic

/close Resolve the ticket, notify the user, and archive the topic
/ban Ban the user and close their support session
/unban Lift the ban — user is notified and can open a new session

🔑  Admin — private DM with bot

/stats Show session counts, active tickets, and daily activity
/broadcast <msg> Send an announcement to all non-banned users at once
Setup

Deployed in five steps.

1

Create your bot

Message @BotFather on Telegram, send /newbot, and copy the API token it gives you.

2

Set up a Forum group

Create a private Telegram group, enable Topics in settings, and add your bot as an admin with the Manage Topics permission.

3

Get your IDs

Forward a message from your group to @userinfobot to get the Group ID. DM it directly to get your personal User ID.

4

Deploy to Render

Fork the repo, create a new Web Service on Render, set gunicorn main:flask_app as the start command, and add the environment variables.

5

Send /start

Message your bot on Telegram. A Forum Topic is created instantly in your group. You're live.
